# 智慧学工 · 场地预约系统原型（cdyy）

中南大学学生工作部「场地预约」板块的可交互 HTML 原型，覆盖后台管理端、师生预约端（PC / 移动）、审批端（PC / 移动）三大端口。

## 在线预览

打开 [首页导航](./index.html) 后可进入各端口演示。首页顶部列出了本轮新增能力，建议按其中的链接逐项验证。

## 目录结构

| 目录 / 文件 | 说明 |
|------------|------|
| `index.html` | 原型导航首页：系统角色、核心业务流程、三端入口 |
| `admin/` | 后台管理端（PC）：场地管理、表单模板、审批配置、预约记录 |
| `user-pc/` | 师生预约端（PC）：场地浏览、四步预约、我的预约 |
| `user-mobile/` | 师生预约端（移动）：同上，移动端布局 |
| `approval-pc/` | 审批端（PC）：待办、审批详情、审批历史 |
| `approval-mobile/` | 审批端（移动）：待办任务、任务详情 |
| `PRD.md` / `PRD.docx` | 产品需求文档 |
| `角色菜单权限表.md` | 各角色的系统菜单与操作事项 |
| `场地预约系统操作手册.md` / `.docx` | 图文操作手册 |
| `manual-screenshots/` | 操作手册插图 |
| `*.py` | 文档生成脚本（PRD 转 Word、权限矩阵、手册生成） |

## 主要能力

- **场地配置**：五步向导（基础信息 → 时段配置 → 表单模板 → 审批流程 → 权限配置）
- **8 种时段策略**：整点制、90 分钟、2 小时、混合制、节次制、半天制、自由时段、**自定义时段**（在开放时间内逐条定义场次，可增删）
- **开放规则**：开放日（预设 / 自定义）、每日多个开放时段（如上午 8:00–12:00、下午 14:00–18:00）
- **场地负责人**：默认为创建人，负责人登录后台只能查看和管理自己负责的场地
- **审批配置**：每级审批可选「指定人员」或「指定角色」，角色支持或签 / 会签，审批人自动获得所审场地的管理权限
- **分支与条件审批**：按申请人身份走不同路径；人数达阈值自动增加校保卫处等节点
- **外链场地**：场地类型选「外部链接跳转」后仅填基础信息即可保存，师生点击直接跳转外部系统
- **表单模板**：13 套模板、9 种字段类型，字段支持拖拽排序

## 说明

- 纯静态 HTML 原型，交互由内联 JavaScript 实现，无后端；页面刷新后数据恢复初始状态。
- 页面中的人名、预约记录均为演示数据。

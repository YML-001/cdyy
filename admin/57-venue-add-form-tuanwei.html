预约表单模板

校团委活动场地已自动套用《中南大学校园文化活动场地申请表》，可按需微调。可从已有模板快速复制，也可自定义字段。拖动字段左侧的 ⠿ 手柄可调整顺序（也可选中手柄后用 ↑ ↓ 键移动）。
快速复制已有模板：
standard（标准会议室） ethnic（民族办场地） sizheng（思政体验课堂） zhixin（知新馆） safety（安全教育） defense（国防教育） psyGroup（心理团辅） wenqu（问渠长廊） tuanwei（校园文化活动场地申请表） 空白模板
系统自动带出（不可编辑） 申借场地使用时间 由师生在「选择场地」「选择时段」步骤中确定
字段名称 类型 必填 规则 操作
⠿ 活动名称 文本 — 编辑 删除
⠿ 活动性质 单选 选项：文艺演出或晚会 / 会议 / 竞赛 / 哲学社科理论类讲座 / 其他 编辑 删除
⠿ 审核通过界面截图 图片上传 仅当 活动性质 = 哲学社科理论类讲座 时显示 编辑 删除
⠿ 是否需要外接设备 单选 选项：是 / 否 编辑 删除
⠿ 租赁设备进场安全管理承诺书 附件 仅当 是否需要外接设备 = 是 时显示先下载模板，修改后上传 编辑 删除
⠿ 租赁设备进场清单 附件 仅当 是否需要外接设备 = 是 时显示先下载模板，修改后上传 编辑 删除
⠿ 主办单位 部门选择 可多选，数据来自学工系统组织机构 编辑 删除
⠿ 承办单位 部门选择 可多选，数据来自学工系统组织机构 编辑 删除
⠿ 预估人数 数字 不超过场地容纳人数 编辑 删除
⠿ 拟邀请嘉宾 文本域 — 编辑 删除
⠿ 活动负责老师 人员搜索 审批第 02 步取此人 同时填写联系电话 编辑 删除
⠿ 联络人 人员搜索 同时填写联系电话 编辑 删除
⠿ 备注信息 文本域 — 编辑 删除
